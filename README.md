# RRP Express Logistics website

## Files to upload

Upload the full contents of this folder to the root of the rrpexpress GitHub repository:

- index.html - home page and transport enquiry form
- attach-vehicle.html - vehicle owner attachment form
- service-areas.html - Anantapur, Hindupur, Tadipatri, Bengaluru and Hyderabad service-area page
- privacy.html - enquiry privacy notice
- styles.css and script.js - shared design and form behaviour
- robots.txt and sitemap.xml - search-engine discovery files

## Temporary images

The cargo and hero images use relevant temporary logistics photos from Unsplash. Replace them later by changing the corresponding image URLs in index.html.

Recommended future replacements:

- hero image: RRP vehicle on an Indian highway
- industrial freight: scrap, minerals or bulk cargo handled by RRP
- construction cargo: pipes, cement or building material load
- FMCG: palletised finished-goods dispatch
- project cargo: machinery, trailer or specialised load

## Partner logos

The trusted-partner section currently uses carefully styled temporary wordmarks based on the references supplied by RRP. Replace each wordmark with an approved original logo file only when that artwork is cleared for website use.

## Enquiry handling

Both forms generate a complete WhatsApp message to +91 90148 84668. Change the number in script.js if another number should receive the website enquiries.

## Important company-history note

The public site deliberately does not state an operating-since year. The supplied corporate profile gives a legal incorporation date of 04 July 2026, while the business history shared verbally is 2020. Publish both only after confirming the approved wording.
